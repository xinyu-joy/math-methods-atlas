# 数学方法地图

从一个问题，找到数学方法。按学科、问题类型与方法名称检索，服务于学习、科研选题和跨领域方法发现。

**网站：** https://xinyu-joy.github.io/math-methods-atlas/

## v0.2 · 2026-11-03

- 63 个 MSC2020 学科目录：20 个原来没有方法条目的学科新增专门导读，另 43 个学科保留方法索引，专门导读仍待补。
- 30 个方法族全部附文献位置、支持的内容和实际核对范围；方法族数量保持 30。
- 5 条具体结论附假设、推导、精确例算和失效边界，另有 3 条有文献依据的跨领域联系，均有独立链接。
- 0 条经过独立同行审阅；例算检查不代替一般证明。文献目录或摘要核对不计为正文结论核验。
- 网站分别呈现内容覆盖与证据深度，不宣称穷尽数学方法，不将未检索到文献认定为创新或研究空白。

## 更新与发布

源文件位于 `math-atlas/`。更新 `main` 后 GitHub Actions 自动构建、检查并发布，只发布 `math-atlas/dist`。不需要服务器数据库或第三方运行依赖。

使用 Node.js 22 或更新版本：

```sh
cd math-atlas
npm run build
npm test
npm run dev
```

维护和内容口径见 [维护说明](math-atlas/README.md)。网站当前数据可下载 JSON、方法 CSV、学科导读 CSV 和例算复核记录；Excel 保留为标明版本的 v0.1 历史快照。
