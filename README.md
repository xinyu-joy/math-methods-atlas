# 数学方法地图

从一个问题，找到数学方法。按学科、问题类型与方法名称检索，用于数学学习、科研选题与跨领域方法发现。

**网站：** https://xinyu-joy.github.io/math-methods-atlas/

## 当前版本 v0.1

- 63 个 MSC2020 一级学科目录、30 个方法族、6 类问题入口。
- 每个方法都有独立链接，包含直观解释、典型问题、条件、结论、局限与文献来源。
- 支持中英文关键词、组合筛选、分享检索结果，以及 Excel、CSV 和 JSON 下载。
- 3 个条目已核对原始论文或综述摘要；0 个完成定理级核验。当前为初步登记版，不代表数学方法的完整清单，也不构成研究空白判定。

## 更新与发布

网站源文件在 `math-atlas/`。推送到 `main` 后，GitHub Actions 自动生成、检查并发布网站。只发布 `math-atlas/dist`。

本地使用 Node.js 22 或更新版本：

```sh
cd math-atlas
npm run build
npm test
npm run dev
```

详情见 [维护说明](math-atlas/README.md)。提出纠错或新增条目时，请附方法编号、来源链接，以及定理编号、章节或页码。

## 来源

学科分类依据 [MSC2020](https://msc2020.org/)，分类原始资料注明 CC BY-NC-SA，具体授权以官方说明为准。中文导航、方法用途和跨领域标签为项目编辑整理；保留原始来源署名和链接，不转载论文全文。
